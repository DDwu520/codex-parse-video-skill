# 平台能力验收表

此表只记录实际完成的验证，不把底层解析器的支持声明当作当前可用结论。平台页面或接口变化后，旧结果可能失效。

当前表内的真实结果均来自 macOS Apple Silicon 环境，不能外推为其他架构或 Windows 已验证。用户已于 2026-08-02 决定暂停新增平台测试，下一阶段优先完成 macOS ARM64、macOS Intel x64 与 Windows x64 的跨平台适配；Windows ARM64 留到后续版本。各环境结果必须在独立矩阵中记录。

状态说明：

- `通过`：已用公开链接完成该路径的真实端到端验证。
- `证据准备通过`：已生成完整可审计证据包，但按用户测试边界未进入仓颉阶段 0 或后续拆解。
- `待验证`：固定解析器已登记该平台，但本版本尚未完成真实端到端验证。
- `受限`：验证时遇到登录、验证码、付费、私密权限、DRM 或平台限制；不绕过。
- `失败`：公开链接在固定解析器中失败，需保留错误与验证日期。
