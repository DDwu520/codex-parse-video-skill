# parse-video v1.0.0-rc.3

这是供真实用户验收的跨平台候选版，不是正式稳定版。

## 下载哪个文件

- Windows 10/11 x64：`parse-video-v1.0.0-rc.3-windows-x64.zip`
- Apple Silicon Mac（M1/M2/M3/M4）：`parse-video-v1.0.0-rc.3-macos-arm64.zip`
- Intel Mac：`parse-video-v1.0.0-rc.3-macos-x64.zip`
- `SHA256SUMS.txt`：三份安装包的完整性校验值

## 这版已经验证什么

- Windows x64、macOS Apple Silicon、macOS Intel x64 的自动化测试通过。
- 三个平台的原生解析器均由对应系统构建并完成基础运行检查。
- 三份安装包均完成安装、文件清单和防篡改校验。
- macOS 包内置运行 Skill 所需的 Python 助手，用户无需预装 Python。

## 仍需真实用户验收什么

- 在真实 Windows 和 Mac 电脑上完成安装、诊断、下载、理解与蒸馏流程。
- 不同平台公开链接的可访问性仍受原平台变化影响；遇到登录、验证码、Cookie、付费、私密权限或 DRM 时不会绕过限制。
- FFmpeg 和本地 Whisper 不是全部打进安装包；诊断程序会报告缺失项。Windows 仅在用户明确确认后安装登记依赖，macOS 当前只报告依赖状态。

请按对应系统测试文档操作，并通过仓库 Issue 反馈结果。未完成真实用户验收前，本版本保持 `candidate` 状态。
