# v1.0.0-rc.2 发布说明

这是修复首轮公开 CI 问题后的 Windows x64 候选版，用于收集真实 Windows 10/11 验收证据，不是正式稳定版。

## 相比 rc.1 的修复

- Windows 安装器和运行助手显式使用 UTF-8，避免中文路径或 JSON 输出触发 `UnicodeEncodeError`。
- 下载失败与超时测试不再隐式依赖 runner 预装 FFprobe。
- Windows 临时目录断言按当前系统路径格式比较。
- 不替换 rc.1 的同名附件，以新的 rc.2 标签和校验值发布。

- 本地 30 条 Skill 测试、5 条安装与清单测试、Go 全量测试及 Skill 结构校验通过。
