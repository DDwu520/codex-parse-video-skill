# v1.0.0-rc.1 发布说明

这是首个 Windows x64 公开候选版，用于收集真实 Windows 10/11 验收证据，不是正式稳定版。

## 本次提供

- Codex Skill 下载、理解、蒸馏三模式。
- Windows x64 解析器及内置 Python 3.13.12 运行时。
- 无管理员权限安装、升级备份、回滚和可恢复卸载。
- 离线 doctor、显式确认的 FFmpeg/Whisper 依赖安装。
- Windows 真实桌面/文档目录、安全文件名、临时媒体和进程树清理。
- 顺序批量下载；批量理解和蒸馏不在 V1 范围。
